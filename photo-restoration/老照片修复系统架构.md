# 孝心帮老照片修复系统架构 v2.0

## 核心理念
取各家开源之长，做不输付费的效果。全部免费、本地运行、诚实透明。

## 管线架构

```
输入照片
    │
    ▼
┌──────────────────────┐
│ 损伤智能分析 (自研)    │
│ 模糊/褪色/划痕/人脸   │
└──────┬───────────────┘
       │
       ▼
┌──────────────────────┐
│ 预处理 (传统CV)       │
│ 去噪/对比度/白平衡    │
└──────┬───────────────┘
       │
       ▼
┌──────────────────────┐
│ 划痕/破损修补          │
│ OpenCV inpaint / LaMa │
└──────┬───────────────┘
       │
       ▼
┌──────────────────────┐
│ 人脸修复              │
│ CodeFormer(结构) →    │
│ GFP-GAN(纹理)         │
└──────┬───────────────┘
       │
       ▼
┌──────────────────────┐
│ 超分增强              │
│ Real-ESRGAN ×2       │
│ SwinIR 去噪          │
└──────┬───────────────┘
       │
       ▼
┌──────────────────────┐
│ 后处理&融合           │
│ 羽化/色彩/抛光        │
└──────┬───────────────┘
       │
       ▼
   修复完成 ✅

第二阶段（规划中）：
   修复完成 ✅ → LivePortrait → 动态视频 (老照片动起来)
```

## 模型清单（全部开源免费）

| 模型 | 大小 | 用途 | 来源 |
|------|------|------|------|
| facexlib | 104MB | 人脸检测 | xinntao |
| GFP-GAN v1.4 | 332MB | 人脸纹理修复 | TencentARC |
| CodeFormer | ~200MB | 人脸结构修复 | sczhou |
| Real-ESRGAN x4plus | 64MB | 真实超分 | xinntao |
| LivePortrait (Phase2) | ~500MB | 老照片活化 | Kuaishou |
| 合计 | ~1.2GB | | |

## 部署方式

三种调用入口：
1. 命令行: `python photo_restoration_agent.py -i input.jpg -o output.jpg`
2. 拖拽修复: `老照片修复工具.bat` 
3. API: `POST /api/photo/restore { image, engine: "local" }`

## 定价策略
- 用户消耗88积分/次
- 成本几乎为零
- 积分做用户黏性
