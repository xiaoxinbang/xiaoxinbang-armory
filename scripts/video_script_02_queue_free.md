/**
 * 短视频脚本 ②：《买东西还能免单？我差点排到了》
 * ===============================================
 * 情绪认知沟通法则 · 讲期待感不讲规则
 * 核心认知：那种"差一点就是我"的感觉，让人上瘾
 * 目标人群：40-70岁，喜欢划算购物的中老年
 * 时长：45-60秒
 */

/* ===== 第1镜 · 开头抓人 ===== */
场景：客厅沙发上，大叔正在喝茶
画面：大叔放下茶杯，一脸"你们猜怎么着"的表情
运镜：中景迅速推近

大叔：
（带着点兴奋）
"昨天我差点就免单了！就差两个人！"

台词注解：开头就制造悬念，让观众想知道"什么免单？"

/* ===== 第2镜 · 讲清楚事情 ===== */
场景：大叔拿着手机展示
画面：特写手机屏幕——商品详情页的排队进度条
运镜：特写手机→切回大叔

大叔：
"我在孝心帮上买了个保温杯，58块钱。
买的时候没多想——结果发现它在搞排队免单。
就是你买东西，平台自动给你排队，排到了那单直接免掉。"

（停顿，笑）
"我昨天晚上看的时候，已经排到倒数第三位了！
今早一看——排到了，但免单的是别人。"

台词注解：用"差点"制造遗憾感和代入感，"替他不甘心"就是最好的钩子

/* ===== 第3镜 · 给认知（核心认知） ===== */
场景：大叔喝口茶，身体后仰，一脸"你品你细品"
画面：轻松自然的聊天状态
运镜：近景

大叔：
"但你猜怎么着？我居然不生气——反而觉得有意思。
那种'差一点就是我'的感觉，让人下次还想买。
而且排队的人越多，说明大家觉得这家店靠谱啊。"

（笑着摇头）
"我现在每天打开App第一件事——看看排到哪了。"

台词注解：转折——从"没中"到"有意思"，传递正向情绪
核心认知："期待感"本身就让人快乐

/* ===== 第4镜 · 结尾轻松收尾 ===== */
场景：大叔拿起保温杯喝一口
画面：自然收尾
运镜：中景，自然光

大叔：
"不管免不免单，东西我是用上了——这保温杯还真挺好使的。
万一哪天排到我了呢？"

（对镜头挤眼）

台词注解：轻收尾，不推不拽。最后的表情让观众会心一笑

轻快吉他，带节奏感但不急促
人声为主，bgm为辅
