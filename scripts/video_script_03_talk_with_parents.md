/**
 * 短视频脚本 ③：《跟长辈聊天，别说事实，说这个》
 * ================================================
 * 情绪认知沟通法则 · 核心方法论输出
 * 核心认知：长辈不缺道理，缺的是被看见的感觉
 * 目标人群：40-60岁子女（付费决策者），及关心沟通技巧的人
 * 时长：50-70秒
 * 定位：这个视频本身就在示范"让人爽的认知"——不是教条，是故事
 */

/* ===== 第1镜 · 开头抓人 ===== */
场景：博主（中年或年轻女性/男性，亲切型）坐在书房或客厅
画面：面对镜头，像跟朋友聊天
运镜：近景，暖色调灯光

博主：
"我发现跟爸妈聊天有一个诀窍——"
（停顿，身体前倾）
"别说事实，说认知。"

台词注解：上来就给"认知"，不说"今天教大家..."（那是说教）
而是"我发现..."（这是分享，让人想听下去）

/* ===== 第2镜 · 对比演绎① ===== */
场景：博主继续面对镜头，用"模拟对话"的方式演绎
画面：博主左右切换角色——一边演"妈"，一边演"自己"
运镜：固定近景，靠面部表情切换角色

博主：
"比如你妈说'今天走了八千步'。"

（切换到"普通子女"模式，面无表情）
"❌ 你说：'不错，再走两千步就一万了。'"

（切换到"正确示范"模式，笑着）
"✅ 你说：'妈你太厉害了！我同事每天走三千步就说累——你这身体比年轻人都好！'"

（切回博主本人）
"你妈听了什么感觉？——爽。明天她能走一万步。"

台词注解：用对比示范，让观众秒懂。
"你妈听了什么感觉？"——这是帮观众感受情绪

/* ===== 第3镜 · 对比演绎② ===== */
场景：博主继续聊天式演绎
画面：同一机位，节奏略快

博主：
"比如你爸说'楼下老王儿子升职了'。"

（错误示范，平淡）
"❌ 你说：'哦，那挺好的。'"

（正确示范，带着"我站你"的表情）
"✅ 你说：'他儿子再升也没用——他哪有您这样的闺女/儿子？天天惦记着您，逢年过节就回来看您。'"

（切回博主）
"你看——事实不重要，重要的是让他觉得'我孩子最懂我'。"

台词注解：这个段子直击子女痛点——"老王儿子升职"是中国父母最爱说的梗

/* ===== 第4镜 · 核心认知金句 ===== */
场景：博主坐直，认真但亲切
画面：暖光聚焦
运镜：慢慢推进到特写

博主：
"跟长辈聊天——他们不缺道理，缺的是被看见的感觉。
你顺着他的情绪夸一句，比给他讲十个道理都有用。"

台词注解：这就是本视频的"认知"——让人有"原来如此"的顿悟感

/* ===== 第5镜 · 结尾钩子 ===== */
场景：博主轻松地靠回沙发
画面：自然状态

博主：
"关注我，每天教你一句让长辈开心的话。"

（笑着补一句）
"别光收藏，今晚就试试。"

台词注解：低门槛行动指令——"今晚就试试"，比"点赞转发"更实在
