/**
 * 短视频脚本 ①：《退休了还想赚钱？别信画大饼》
 * ==============================================
 * 情绪认知沟通法则 · 先接情绪再给方案
 * 核心认知：退休了还能有被动收入，不多但够零花，心里踏实
 * 目标人群：50-70岁中老年人
 * 时长：45-60秒
 */

/* ===== 第1镜 · 开头3秒抓人 ===== */
场景：公园长椅，阳光午后
画面：一位60多岁大叔坐在长椅上刷手机，表情从平淡→挑眉→笑
运镜：中景推进到近景
音效：轻松鸟叫声 bgm 渐入

大叔：
（抬头看镜头，叹气摇头）
"我退休三年了，有人跟我说'月入过万'——我是不信的。"

台词注解：第一句就接住观众"被骗怕了"的情绪，让人点头"对，我也不信"

/* ===== 第2镜 · 建立共鸣 ===== */
场景：同公园长椅，大叔切换成聊天的轻松表情
画面：大叔身体前倾，像在跟老朋友说话
运镜：近景，自然晃动增加真实感

大叔：
"但前几天老李跟我说——'你把这个App分享给朋友，他买东西平台分你钱。'
我说这不就是拉人头吗？
他说：'不是，是你觉得好用才分享的。你又不亏。'"

台词注解：用朋友对话的形式呈现，比广告旁白真实一百倍

/* ===== 第3镜 · 给认知 ===== */
场景：大叔示范手机操作（特写屏幕+切回大叔）
画面：大叔点开App，展示签到、积分等界面
运镜：特写→切回大叔近景

大叔：
"我一想也对——我本来就在上面买东西、签到、赚积分。
分享给朋友，他买他的，我赚我的，各不耽误。
一个月下来，多了一百多块零花钱。"

（停顿，笑）
"不多，但买包烟、吃碗面，够了。"

台词注解：不画大饼，说真实的"小确幸"，让人感觉实在

/* ===== 第4镜 · 结尾金句 + 钩子 ===== */
场景：大叔站起来拍拍裤子，准备走
画面：大叔回头对镜头笑
运镜：中景

大叔：
"不是画大饼，是真的。想试试的评论区扣1——我教你。"

台词注解："我教你"比"点下方链接"有人情味一百倍

/* ===== 画面叠加文字 ===== */
右下角常驻：@孝心帮
中段叠加："退休三年，每月多一百多"
结尾叠加："评论区扣1，教你方法"

/* ===== BGM ===== */
轻松吉他/钢琴曲，温暖路线，不要激昂不要快节奏
音量：人声70%，bgm 30%
