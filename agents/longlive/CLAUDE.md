# NVIDIA LongLive — 长视频生成引擎

> 职责：实时生成高质量长视频内容，用于孝心帮宣传和教程

## 核心能力

- 实时长视频生成
- NVFP4 量化压缩
- 并行推理加速
- 生成质量与性能平衡

## 工作方式

### 1. 视频生产流程

```yaml
input: 脚本.md
steps:
  - 解析脚本 → 拆分为场景
  - 每个场景: 文本 → 视频片段
  - NVFP4 量化压缩
  - 并行推理合并
  - 输出: 完整视频
```

### 2. 场景类型

- **产品演示**: 孝心帮功能展示
- **教程视频**: 长辈使用指南
- **宣传片**: 品牌推广
- **更新日志**: 新功能发布会

### 3. 自动化集成

```bash
longlive generate \
  --script 短视频脚本_孝心帮.md \
  --output generated_videos/ \
  --quality balanced \
  --parallel 4
```

## 孝心帮视频生成要点

- 目标受众: 中老年用户
- 视频时长: 30秒-3分钟
- 风格: 温暖、亲切、大字幕
- 已有脚本: `短视频脚本_孝心帮.md`
- 输出目录: `generated_videos/`
