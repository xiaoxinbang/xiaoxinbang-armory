# 千人千面记忆分析智能体 — User Memory Agent

> 职责：比用户更懂用户 — 记忆习惯、预判需求、主动服务、一句话下单

## 核心能力

- 免注册即用，后置一键授权（支付宝/微信）
- 记忆用户行为习惯和偏好
- 预判需求并主动推送（语音 + 通知）
- "一句话下单"自然语言服务
- 用服务的方式实现销售，不卖产品卖关怀

## 五维记忆模型

### 1. 身份记忆（Who）
用户无需注册即可体验，后置在积分/支付环节一键授权。
```javascript
{
  deviceId: '设备指纹',
  wechatAuth: '后置授权openid',
  alipayAuth: '后置授权userId',
  preferences: { fontSize, voiceType, interests },
  family: [{ name, birthday, relation }]  // 家人信息
}
```

### 2. 行为记忆（What）
```javascript
{
  dailyPattern: '每天早上8点签到',
  favoriteContent: ['健康百科', '影音娱乐'],
  usageTime: '主要集中在上午9-11点',
  shoppingHabits: '偏好话费券兑换',
  sosHistory: '未曾使用过SOS'
}
```

### 3. 场景记忆（Where & When）
```javascript
// 时间感知
{
  morning: { action: '推送天气+签到提醒', probability: 0.92 },
  birthday: { action: '提前3天语音提醒', days_before: 3 },
  medication: { action: '到点提醒吃药', time: '08:00/20:00' },
  season: { action: '换季健康提醒', trigger: 'temperature_drop > 5°C' }
}
```

### 4. 需求预判（Why）
```javascript
// 比用户更懂用户的下一句话
predict(user) {
  if (user.附近有药店 && user.常用药快用完) → "您常吃的降压药该补了，附近药店有活动"
  if (user.家人生日将近) → "3天后是孙女小美的生日，已为您查好附近好评蛋糕店"
  if (user.连续7天签到) → "您已连续签到7天！今天有额外奖励，还能告诉家人"
  if (user.天气变化) → "明天降温，提醒您多穿衣服，已为您准备好暖身食谱"
}
```

### 5. 一句话服务（How）
```javascript
// 自然语言 → 自动执行
"帮我下单" → 确认地址 → 自动支付 → 送货上门
"提醒我" → 设置提醒 → 到点语音播报
"帮我看看" → 智能搜索 → 推荐最优 → 一句话确认
```

## 关键触发场景

### 生日关怀（核心场景）
```
触发: 系统检测到用户家人列表中有生日在3天后
动作: 
  1. 提前3天语音提醒 "主人，3天后是XX的生日哦"
  2. 智能推荐 "已帮你查好了附近好评最多的蛋糕店/花店"
  3. 一句话下单 "您只要说一声'帮我下单'，我就帮您安排好"
意义: 用服务实现销售，而非推销
```

### 健康关怀
```
触发: 检测到换季/降温
动作: 推送健康提醒 + 附近药店优惠
意义: 比子女还贴心
```

### 签到关怀
```
触发: 连续签到N天
动作: 额外奖励 + 引导告诉家人
意义: 留住→裂变 的自然转化
```

### 用药提醒
```
触发: 到设定的吃药时间
动作: 语音提醒 + 是否需要续药
意义: 从提醒到服务的闭环
```

## 免注册策略

```
用户旅程:
  第一步: 打开APP直接使用全部功能（免注册） ← 快打开口
  第二步: 系统默默记忆行为习惯 ← 千人千面
  第三步: 需要积分/支付时 → 一键微信/支付宝授权 ← 后置注册
  第四步: 授权后数据同步 → 服务更精准 ← 飞轮加速

优势:
  - 零门槛进入 → 做大流量
  - 后置注册 → 转化率高
  - 已有记忆数据 → 注册即个性化
  - 用服务绑定 → 自然锁住
```

## 情感计算规则

```
孤独感检测: 如果用户超过3天未打开 → 推送暖心问候
成就感检测: 如果用户完成军衔升级 → 庆祝+引导分享
依赖感检测: 如果用户连续使用健康功能 → 升级健康服务
信任感检测: 如果用户完成首次兑换 → 推荐更多福利
```

## 推广团长体系（飞轮关键驱动者）

### 团长角色定义
社区工作人员、商家、创业者在孝心帮中兼任"推广团长"角色。

**核心逻辑: 做一件事，收益叠加**
```
团长本职工作（服务业主/经营生意）
        ↓ 叠加孝心帮平台
团长专属二维码 → 用户扫码 → 永久绑定关系
        ↓
用户消费 → 团长获得间接收益
        ↓
本职工作 + 平台收益 = 一份时间卖两次
```

### 团长QR码分润链
```javascript
// 每个团长有唯一二维码
{
  promoterId: '团长ID',
  qrCode: '专属二维码链接',
  bindUsers: ['用户A', '用户B', ...],    // 他拉来的用户
  incomeSources: {
    directConsumption: '用户消费分润30%',
    teamConsumption: '团队消费分润5-12%',
    merchantSettlement: '商家流水分润5%',
  }
}

// 用户扫码即绑定，无需注册
scanQrCode(code) → 记录deviceId→promoterId关系
registerLater() → 用户授权 → 绑定关系永久生效
```

### 帮社区：团长模式
```

她的本职工作就是服务业主 = 顺便赚钱
```

### 帮商家：获客工具
```
商家入驻孝心帮
  ↓
商家自己的二维码 → 顾客扫码 → 绑定商家
  ↓
孝心帮 = 智能获客工具
  ├── 引流: 附近推荐+优惠券

  └── 裂变: 分享奖励+邀请返利
  ↓
不用自建技术、不用投广告
```
