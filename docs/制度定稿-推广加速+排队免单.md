# 孝心帮 · 推广加速+排队免单 制度定稿

> 定稿日期：2026年6月6日（V3修正版）
> 状态：✅ 已精算验证（平均净利率6.4%，最极端情况10.7%）

---

## ⚠️ 铁律：所有拨比按毛利算

**所有比例基于毛利（售价 - 商品成本），不是售价。**
这是制度的命根子，千万不能搞错。

为什么？
- 商家让利 → 产生毛利 → 按毛利分配 → 永远在利润范围内分钱
- 如果按售价分 → 可能分出去的钱比赚的还多 → 必死

> **记住：毛利拨比 = 安全。售价拨比 = 找死。**

## 一、一句话说清楚

**你在平台消费 → 参与排队免单 → 推广4个朋友加速免单 → 免单后推广赚钱**

---

## 二、排队免单（怎么免）

| 商品类型 | 什么意思 |
|---------|---------|
| 4出1 | 4个人排，1个人免单（高毛利商品，空间大） |
| 5出1 | 5个人排，1个人免单（常规商品） |
| 6出1 | 6个人排，1个人免单（低毛利商品） |

**免单的钱从哪里来？** 平台从每笔收入中拿出**40%**作为排队免单基金，谁排到了就给他免单。

---

## 三、推广加速（怎么免单）

**推广4个朋友，你自己也能免单！** ⭐ **仅此一次**

每推荐1个朋友来消费，你拿加速奖励（**不叠加直推**，目的是让你自己免单）：

| 第几个 | 加速奖励 | 归谁 |
|-------|---------|------|
| 第1个 | **10%** | 你拿加速奖，师傅拿间推10% |
| 第2个 | **20%** | 你拿加速奖，师傅拿间推10% |
| 第3个 | **30%** | **全归你**，跟师傅没关系了 |
| 第4个 | **40%** | **全归你**，跟师傅没关系了 |

**算总账：** 10%+20%+30%+40% = **100% = 你自己的消费金额回来了，等于免单！**

> ⚠️ **重要：加速期不叠加直推奖。** 加速奖励就是帮你免单用的，不是用来赚钱的。

### 加速免单 vs 排队免单（不冲突）

```
排队免单：自动排队，循环免单
  → 排到了免一单 → 自动进下一轮继续排 → 还能再免
  （无限循环，一直排一直有机会）

加速免单：推4个朋友，主动提前免单
  → 加速奖10%+20%+30%+40%=100% → 自己免单
  （仅此一次加速机会）

两件事互不影响，可以同时享受：
→ 推4人加速免单后，排队名额还在，继续排着
→ 排到了还能再免，循环不断
→ 等于花一次钱，有机会免无数次
```

## 四、师徒关系

| 角色 | 前2个新人 | 后2个新人 |
|------|----------|----------|
| **你** | 拿加速奖10%、20% | 拿加速奖30%、40% |
| **师傅** | 拿间推10%×2人 | 不再拿 |
| **新人归属** | 归师傅团队 | 归你自己团队 |

---

## 五、免单完成后（老会员规则）

> 加速免单 **只有一次**。免完之后，你就是老会员了。

**以后推广/复购统一按老会员规则：**

| 奖励 | 比例 | 说明 |
|------|------|------|
| 直推 | 毛利润的**20%** | 约等于售价的10%（不分什么商品） |
| 间推 | 售价的**10%** | 你师傅/上级拿 |
| 复购 | 同上 | 你自己复购也算，规则一样 |

> **简单说：加速期是为了免单，免单后是为了赚钱。两阶段分开算。**

---

## 六、钱怎么分（按毛利算）

> 所有比例基于**毛利**（售价 - 商品成本），不是售价。
> 假设毛利率50%（即售价100元、成本50元、毛利50元）：

```
售价100元
  ├─ 商品成本 50元
  └─ 毛利 50元（100%==拨比基数）
       ├─ 40%（20元）→ 排队免单基金
       ├─ 35%（17.5元）→ 加速奖励（售价25%≈毛利35%）
       ├─ 10%（5元）→ 间推（师傅拿）
       ├─ 5%（2.5元）→ 英雄榜
       ├─ 5%（2.5元）→ 推商家
       └─ 5%（2.5元）→ 平台

老会员阶段（加速免单后）：
       ├─ 40%（20元）→ 排队免单基金
       ├─ 20%（10元）→ 直推（毛利×20%）
       ├─ 10%（5元）→ 间推
       ├─ 5%（2.5元）→ 英雄榜
       ├─ 5%（2.5元）→ 推商家
       ├─ 5%（2.5元）→ 平台
       └─ 余15%→平台额外利润

提现扣6%→3%税+3%积分池
```

**按毛利算各项占比：**
| 项目 | 加速阶段 | 老会员阶段 |
|------|---------|-----------|
| 排队免单 | 40% | 40% |
| 加速奖励 | **35%**（售价25%折算） | 无 |
| 直推 | 无 | **20%**（毛利×20%） |
| 间推 | 10% | 10% |
| 英雄榜 | 5% | 5% |
| 推商家 | 5% | 5% |
| 平台 | 5% | 5%+余15% |
| **合计** | **100%** | **85%+15%余** |

## 七、精算结论（安全吗？）

| 情况 | 平台净利率（占售价） | 结论 |
|-----|----------|------|
| 正常运营（5出1为主） | **4.7%** | ✅ 安全 |
| 高毛利商品多（4出1多） | **3.1%** | ✅ 安全 |
| 低毛利商品多（6出1多） | **7.0%** | ✅ 更赚 |
| 最极端（全部7出1） | **10.7%** | ✅ 稳得很 |

**拨比占毛利25%（占售价12.5%），平均净利率6.4%，所有场景都为正。**

## 八、提现规则

| 提现类型 | 费率 | 说明 |
|---------|------|------|
| 推广者提现 | 扣**6%** | 3%交税 + 3%进积分基金池 |
| 消费者全返提现 | 扣**10%** | 进排队免单基金池 |
| 代理商转对公 | **0%** | 凭发票抵扣 |

## 九、一句话总结

> **推4人→主动加速免单（加速奖不叠加直推）**
> **排队照排→还能再免一次（两个通道互不冲突）**
> **免单后→推广赚钱（直推+间推，正常拿）**
> **复购/其他商品→统一老会员规则**
> **简单，好懂，拨比扛得住。**
