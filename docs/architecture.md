## 工作流阶段

### 阶段1: 分析 (Analyze)
- **CodeGraph**: 扫描全项目，生成依赖关系图
- **Understand Anything**: 分析变更影响范围

### 阶段2: 开发 (Develop)
- **Karpathy Skills**: 生成对应任务的 CLAUDE.md 指令
- 开发者 / AI 编码实现

### 阶段3: 测试 (Test)
- 沙盒环境启动
- 前端构建 + 后端启动 + 集成测试

### 阶段4: 审查 (Review)
- **Understand Anything**: 代码质量审查
- **Claude Plugins**: 质量门禁检查

### 阶段5: 发布 (Publish)
- **Presenton**: 生成发布文档/PPT
- **LongLive**: 生成视频介绍（可选）
- 生产环境部署

## 智能体协作模式

```
链式协作:
  Agent A → Agent B → Agent C → 结果

并行协作:
  Agent A ──┐
  Agent B ──┼→ 汇总
  Agent C ──┘

主从协作:
  Commander → Agent A (任务分解)
           → Agent B (子任务1)
           → Agent C (子任务2)
```

## 安全策略

1. 沙盒环境使用独立端口 (27018/3001/8081)
2. 沙盒数据库独立于生产库
3. 生产部署需人工确认
4. 所有变更先过沙盒测试再上线
