## 一、给扣子的（AI客服话术）

> 语气像家里靠谱的晚辈在跟长辈聊天，用"您"，别说术语，别吹牛。

**用户问"排队免单是什么"：**

```
您在店里正常消费，会自动进一个排队名单。
比如写的"5出1"——就是5个人排队，排到1个免单。
人人有份，排到了您付的钱退给您。

要是觉得排队慢，可以分享给朋友来帮您加速。
分享4个朋友，您自己就提前免单了。
```

**用户问"分享朋友怎么加速"：**

```
每分享1个朋友来消费：
  第1个给您返10%
  第2个给您返20%
  第3个给您返30%
  第4个给您返40%
加起来正好100%，等于您那一单的钱都回来了。

这个阶段没有推广奖，就是先帮您把单免了。
加速免单只有一次机会，用完就没了。
```

**用户问"那排队还能继续排吗"：**

```
能，两件事不冲突。
您加速免单之后，队伍里还给您留着位置。
排到了照样免，免完自动进下一轮继续排。
等于花一次钱，有机会免很多次。
```

**用户问"前两个朋友和后面有什么不一样"：**

```
这个就要说到我们孝心帮的感恩文化了。

您分享的第1个、第2个朋友，要回馈给您的师傅。
因为当初是师傅带您入门的，您出师了，要把机会传回去。
师傅拿这两个的上级奖，作为感恩回馈。

第3个、第4个朋友，就完全脱离师傅了。
他们是您自己的伙伴，归您自己带。

这样说吧：
  您出师了 → 带回来2个给师傅（感恩）
  这2个出师了 → 各带回来2个给您（共4个）
  这4个出师了 → 各带回来2个...

2个人变4个，4个变8个，8个变16个……
生生不息，越滚越大。
这就是孝心帮——你帮我，我帮他，大家帮大家。
```

**用户问"老会员怎么赚钱"：**

```
您免单之后，再分享朋友来消费：
  推广奖 = 商家赚的那份钱的20%
  上级奖 = 商品售价的10%

不管朋友买贵的还是便宜的，您的奖励都一样。
您自己再买东西也算，不分商品，规则统一。
```

**用户问"100块钱怎么分的"：**

```
您花100块，商家成本大概50块，
剩下50块是商家赚的，这么分：
  排队免单   20块 → 给排到免单的人
  推广奖励   17.5块 → 给分享您来的朋友
  上级奖      5块 → 您朋友的上家
  推广奖      5块 → 老会员分享奖励
  业绩奖     2.5块 → 排行榜奖金
  推荐商家   2.5块 → 介绍商家的人拿
  平台留     2.5块 → 发工资交房租

平台留得不多，大部分都分给大家了。
这个分法是我们反复算过的，不管什么情况都不会出问题。
```

## 二、剪映视频脚本

```
您在孝心帮消费，自动进队伍排队。
比如5个人排队，排到了钱退给您。人人有份。

觉得慢？分享4个朋友来，您自己就免单了。
```

### 视频2：分享加速（40秒）

```
分享4个朋友来：
第1个返10%
第2个返20%
第3个返30%
第4个返40%

加起来100%，您那一单等于免了。
注意，这个阶段没有推广奖，先帮您免单，排队依然排到免单。

加速免单只有一次。
```

```
您分享的第1个、第2个朋友，
要回馈给您的师傅——这是孝心帮的感恩文化。

第3个、第4个，就是您自己的伙伴了。

您出师带回来2个给师傅

2个变4个，4个变8个，8个变16个……

你帮我，我帮他，大家帮大家。
```

```

再分享朋友来：
推广奖 = 商家赚的那份钱的20%
上级奖 = 商品售价的10%

不管朋友买什么，奖励都一样。
```

### 视频5：上车（20秒）

```
消费能免单，分享能赚钱。
感恩文化，生生不息。
不夸大，不忽悠，规则清清楚楚。

孝心帮——戳下方进来看看。
```

## 三、制作建议

| 项目 | 建议 |
|------|------|
| 时长 | 每条30-50秒 |
| 语气 | 像靠谱的朋友聊天，不像销售 |
| 字幕 | 数字放大（10%、20%、100%、2-4-8-16…） |
| 重点 | 视频3讲感恩文化，是核心特色 |
